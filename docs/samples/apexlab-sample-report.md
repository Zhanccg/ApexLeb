# 研究报告：车速与侧向加速度

> ApexLab 极速科研实验室 · 弯道与抓地 · 生成时间 2026/11/19 23:45:24

## 1. 研究背景

在相同弯道半径与路面附着条件下，车速 v 如何影响赛车过弯时的侧向加速度 ay？

研究目的：在控制其余参数的条件下，量化车速 v对侧向加速度 ay的影响，并通过对照实验检验研究假设。

## 2. 研究假设

- **陈述**：侧向加速度 ay 随车速 v 增大而增大，且与 v² 成正比。
- **预期方向**：非线性关系
- **物理依据**：ay = v²/R

## 3. 理论模型

简化过弯模型（水平道路、匀速圆周运动、忽略空气动力与纵向轮胎力）：

```
v[m/s] = v[km/h] / 3.6        # 单位换算
ay     = v² / R               # 侧向加速度, m/s²
ay_max = μ × 9.81             # 最大简化侧向加速度, m/s²
λ      = ay / ay_max          # 附着利用率, 无量纲
v_limit = sqrt(μ × 9.81 × R)  # 简化临界速度, m/s
```

模型版本：cornering-flat-noaero-v1。λ > 1 仅表示在该简化模型中无法维持指定半径的匀速圆周运动，不构成真实车辆失控预测。

## 6. 数据分析

**方法**：绘制 ay–v 对照曲线（水平汇总 n=样本数）并比较水平间差异

## 7. 科研结论

在 R=50 m、μ=1 条件下，侧向加速度需求与车速平方成正比；54→72→90 km/h 对应 4.50→8.00→12.50 m/s²，假设被数据支持。

## 8. 模型局限性

本实验采用简化车辆质点模型：不包含完整轮胎特性、空气动力（下压力与阻力）、纵/横向载荷转移与真实车辆控制过程；结论仅适用于所测参数取值范围。

研究者补充：结论仅适用于所测取值范围；简化质点模型未含轮胎特性、气动与载荷转移。

分析阶段声明：仅覆盖 54–90 km/h、R=50 m、μ=1；90 km/h 工况 λ=127.4% 已超出简化附着极限。
